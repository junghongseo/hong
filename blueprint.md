# Hong Project Blueprint

## Overview

A simple "Hello World" web page with a dark/white mode toggle feature.

## Style, Design, and Features

*   **Initial Version:**
    *   A single `index.html` file with "Hello, world!" heading.
    *   A "Press me" button with a console log action.
*   **Dark/White Mode Feature:**
    *   A "Toggle Theme" button is added to `index.html`.
    *   `style.css` defines color variables for light and dark themes.
        *   Light theme (default): white background, black text.
        *   Dark theme: dark background (#121212), white text.
    *   `main.js` contains the logic to toggle a `.dark-mode` class on the `<body>` element when the "Toggle Theme" button is clicked.
